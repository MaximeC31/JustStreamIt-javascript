# JustStreamIt

Interface web de consultation de films utilisant l'API locale OCNovels.

## 🚀 Installation et Lancement

1. **Lancer l'API locale**
   Assurez-vous que l'API Python est active sur `http://localhost:8000`.

2. **Lancer l'application**
   Ouvrez simplement le fichier `index.html` dans votre navigateur ou utilisez une extension type "Live Server".

## 🛠️ Technologies

- **HTML5 / CSS3** (Tailwind CSS via CDN)
- **JavaScript Modern** (Modules ES6, Fetch API)
